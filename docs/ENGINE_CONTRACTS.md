# NOVA Engine Contracts

`nova-intelligence` owns the core runtime contracts that can be exported to local AIs, connector repos, and SDK packages.

## First Engine Families

- Coding Harness: intake, route, build, verify, package, handoff.
- Multi-AI Modal Products: product surfaces, AI roles, workflows, proof gates.
- CPL Script Family: Latin action, Greek compute notation, Sanskrit proof/law notation, Hanzi taxonomy, symbols.
- Polyglot Engine Ring: C++, Rust, Go, Python, TypeScript, Julia, Motoko, SQL, proof languages.
- External AI Connector Platform: Caffeine CLI, Caffeine MTP/MCP, Grok Build, generic agent servers.

## Contract Law

Each engine contract must include:

1. Name and authority.
2. Inputs and outputs.
3. Boundary law.
4. Proof gates.
5. Handoff target.
6. Verification path.
