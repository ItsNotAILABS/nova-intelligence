# nova-intelligence

Core intelligence runtime exports and proof-bearing engine contracts for the NOVA repo family.

## Role

This repository owns the reusable intelligence contracts that other repos consume:

- Coding Harness
- Multi-AI Modal Products
- CPL Script Family
- NOVA Polyglot Engine Ring
- External AI Connector Platform

## Current Files

- `nova-intelligence.manifest.json` — repo role, runtime surfaces, proof gates, and handoffs.
- `docs/ENGINE_CONTRACTS.md` — first engine contract law.

## Handoffs

- `nexus` registers this repo in MDFUC.
- `PhantomSDK` packages these contracts for builders and local AIs.
- `x-mcp-skills` turns connector contracts into skills.
