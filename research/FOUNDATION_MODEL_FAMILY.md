# Codex Phantasmatis Foundation Model Family

## Source Status

This packet defines foundation-model runtime profiles, not trained neural weight files. MESIE is the processor. House Codex provides governance. The Python runtime provides API, proof ledger, dashboard, benchmark, and orchestration.

## Family

### 1. Medina ORIGO

Role: crown governance, orchestration, proof, permanence, and lifecycle authority.

Primary house: Medina

Owns:

- trunk law
- attestation
- proof replay
- release gating
- lifecycle coordination

Use when a task asks what should become permanent, what should be promoted, what belongs in trunk, or how a multi-agent/product system should be governed.

### 2. Substratum MESIE

Role: builder-server model for tools, APIs, dashboards, terminal intelligence, and runtime maintenance.

Primary house: Substratum

Owns:

- dashboard/service build paths
- API/server runtime
- MESIE processing
- terminal intelligence
- tests and rollback checks
- operational maintenance

Use when the model must build the thing, serve the thing, maintain the thing, and keep proof of what changed.

### 3. Civitas Expressio

Role: business lifecycle model for customer workflows, marketing, support, education, and feedback loops.

Primary house: Civitas

Owns:

- customer segmentation
- outreach sequences
- support flows
- public-facing language
- feedback capture
- ethical/consent checks

Use when the system must move from internal intelligence into customer-facing product life.

## MESIE Processor

Every run passes through MESIE:

- text hash
- spectral entropy
- dominant frequency bin
- total power
- phonetic topology

This makes the family processor-visible and proofable even before an LLM adapter is added.

## Benchmark

The first benchmark tests whether the family can route tasks across:

- dashboard/server maintenance
- product shipping and rollback
- customer outreach and feedback
- foundation/trunk permanence
- MESIE terminal telemetry

The current benchmark is deterministic and structural. It does not claim neural reasoning quality. It verifies that model selection, lifecycle planning, deliverables, product surfaces, and proof gates are present.
