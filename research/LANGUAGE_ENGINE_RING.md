# NOVA Polyglot Engine Ring

Languages are not interchangeable skins. In NOVA, each language is an engine substrate with a job, a house, a proof path, and a boundary.

## Core Routing Law

Python coordinates, TypeScript faces users, C++/Rust/Julia compute and guard, Go serves, Motoko preserves sovereign state, SQL records consequence, and proof languages certify law.

## Why C++ Exists Here

C++ is **FERRUM Core** because it belongs closest to the metal. It should not carry the whole product, but it should power the runtime where speed, memory control, native libraries, and compiled kernels matter.

FERRUM owns:

- MESIE FFT, PSD, and signal kernels
- local vector-search kernels
- audio, video, image, and file-system indexing
- WebAssembly compute modules
- native desktop runtime extensions

FERRUM proof gates:

- compile with warnings treated seriously
- benchmark the hot loop
- run sanitizer or fuzz path for memory-risk code
- smoke-test Wasm imports/exports when browser-bound

## Cross-Language Boundary Law

No language writes directly into another language's state authority. Cross-language movement routes through Translatio contracts:

- API schemas
- FFI boundaries
- WASM imports/exports
- event ledgers
- database migrations
- MCP tool contracts
- proof manifests
