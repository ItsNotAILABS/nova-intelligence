# CPL Script Family

CPL is not only a programming-language list. It is a governance/action language family.

The terminal IME setting matters because it exposes the real boundary: the command channel needs a stable input mode. Latin is the safest portable command layer, but CPL can still use Greek, Sanskrit/Devanagari, Hanzi, and mathematical symbols as protocol notation when every symbol has a machine-readable alias.

## Core Law

CPL uses ancient scripts as governance/action notation and symbolic protocol authority. Executable code still preserves valid runtime syntax.

## Script Layers

| Layer | Script | House | Runtime Role |
| --- | --- | --- | --- |
| Latina Actio | Latin | Medina / Translatio | Governance actions, CLI stability, protocol verbs, portable identifiers. |
| Hellenikos Logos | Greek | Substratum | Mathematical, harmonic, spectral, coherence, and compute notation. |
| Samskrta Dharma | Sanskrit / Devanagari | Medina / Cura | Law, invariant, proof, care, continuity, and non-fragmentation notation. |
| Hanzi Ming | Mandarin / Hanzi | Civitas / Expressio | Semantic product labels, civic taxonomies, memory names, visual categories. |
| Symbola Status | Mathematical symbols | Translatio | State transitions, proof operators, route diagrams, compact protocol gates. |

## Practical Mapping

- Python remains executable Python, but CPL names its orchestration layer through **Latina Actio**.
- Julia remains executable Julia, but its math layer can use **Hellenikos Logos**: `phi`, `lambda`, `delta`, `sigma`, `omega` aliases for symbolic forms.
- Haskell/Lean remain valid proof languages, but the law/proof doctrine can use **Samskrta Dharma** with ASCII aliases such as `dharma`, `karma`, `sutra`, and `pramana`.
- TypeScript/SQL surfaces may use **Hanzi Ming** for compact product and memory taxonomies when backed by aliases.
- All route diagrams may use **Symbola Status** operators when paired with portable aliases.

## Translatio Rule

Every non-Latin symbol used in a runnable artifact needs a Latin or ASCII alias for terminal, API, package, and Git portability.

| Symbol | Alias | Meaning |
| --- | --- | --- |
| `phi` | `phi` | coherence ratio / bounded scaling |
| `delta` | `delta` | state difference / transition |
| `dharma` | `dharma` | law / invariant |

## Runtime Use

CLI:

```bash
PYTHONPATH=. python codex_cli.py cpl-family
PYTHONPATH=. python codex_cli.py cpl-route "Julia Greek phi coherence kernel"
```

API:

```bash
curl -s http://127.0.0.1:8765/cpl/language-family
curl -s http://127.0.0.1:8765/cpl/route \
  -H 'Content-Type: application/json' \
  -d '{"intent":"Haskell Sanskrit dharma proof membrane"}'
```

Browser terminal:

```text
cpl Julia Greek phi coherence kernel
```
